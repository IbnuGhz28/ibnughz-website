Waktu saya terbatas, tetapi saya ingin terus belajar dan menghasilkan karya. Itu alasan saya mulai membangun Personal Work Assistant.

Saya belajar melalui praktik: mencoba, memeriksa hasil, lalu mencatat apa yang saya pahami. Dari perjalanan ini, saya ingin membuat konten, panduan, dan tools yang juga bermanfaat bagi orang lain.

02 / Sedang dibangun

Proyek saya

Dalam pengembangan

Personal Work Assistant

Proyek asisten pribadi untuk membantu pembelajaran, dokumentasi, dan pengelolaan pekerjaan. Target berikutnya adalah mengolah catatan praktik menjadi bahan konten dan karya digital.

Sudah diuji: database SQLite serta tambah, baca, dan ubah tugas melalui Python.

Langkah berikutnya: menyelesaikan fitur hapus tugas dan membangun backend API.

Dashboard dan otomatisasi AI masih dalam rencana.

03 / Learning journal

30 Oktober 2026 · Journey 001

Awal Saya Membangun Personal Work Assistant

Dimulai dari menata folder, membagi peran ChatGPT dan Claude, serta menyiapkan dua Custom Skills untuk membantu belajar.

Baca cerita lengkap

Saya ingin punya asisten kerja pribadi yang membantu saya belajar, mencatat, dan membuat sesuatu dengan lebih rapi. Karena masih pemula, saya memulainya dari menyiapkan tempat dokumentasi dan membagi peran AI.

Pada 30 Oktober 2026, saya mulai menata folder di laptop untuk menyimpan catatan belajar, eksperimen, konten, proyek, dan ide produk digital.

Saya menggunakan ChatGPT sebagai pendamping berpikir, perencana, dan evaluator. Claude membantu melaksanakan tugas menggunakan Custom Skills yang saya siapkan.

Dua Skill awal saya adalah Motion Graphic Edukasi untuk membantu menyusun ide, naskah, dan storyboard video pendek; serta Digital Learning Journey untuk mendokumentasikan proses belajar.

Saya juga mengaktifkan fitur pembuatan file di Claude. Catatan pembelajaran pertama menjadi percobaan awal saya menghasilkan file yang bisa diunduh dan disimpan.

Pelajaran pertama saya: persiapan folder, instruksi, dan pembagian peran membantu proses belajar terasa lebih terarah. Efektivitasnya dalam pekerjaan sehari-hari masih perlu saya uji.

Langkah berikutnya adalah memakai susunan ini untuk satu tugas nyata, lalu mencatat apa yang berhasil dan apa yang perlu diperbaiki.
